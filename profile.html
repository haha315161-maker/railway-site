⚡ İlginç Kod

JavaScript ile rastgele renk oluşturma: 

function randomColor() {
  const chars = "0123456789ABCDEF";
  let color = "#";

  for (let i = 0; i < 6; i++) {
    color += chars[
      Math.floor(
        Math.random() * 16
      )
    ];
  }

  return color;
}

console.log(randomColor());
